# 进化之路

这是一个用寓言故事学习重要概念与理念的故事集。

在线阅读：[weird-web-lab 中的进化之路](https://haiyanyoudiangui-creator.github.io/weird-web-lab/experiments/evolution-road/)

## 内容结构

- `storys.md`：所有故事与概念解释的总文档
- `storys.html`：故事目录首页
- `*-counterfactual.html`、`*-updating.html` 等：每篇故事的独立页面
- `storys.css`：目录页和故事页共用样式

每篇新故事都会使用不同的叙事场景和隐喻，尽量覆盖金融、心理、统计、科学、历史、艺术、体育与日常生活等领域，避免重复使用同一种故事模板。
